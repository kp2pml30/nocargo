# nocargo

Build Rust crates with Nix: 1 derivation per crate, no `cargo` at build time.

[![CI](https://github.com/kp2pml30/nocargo/actions/workflows/ci.yaml/badge.svg)](https://github.com/kp2pml30/nocargo/actions/workflows/ci.yaml)
[![license](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

> [!WARNING]

## Background

A fork of [oxalica/nocargo](https://github.com/oxalica/nocargo), heading towards a fully in-house implementation.

- No IFD (import-from-derivation): `Cargo.lock`, `Cargo.toml` and the crates.io index are read at evaluation time
- No `cargo` during builds, only `rustc`
- No hash prefetching or code generation; `Cargo.lock` is still produced by `cargo`
- Crate-level caching, shared between projects
- [nixpkgs] integration for non-Rust dependencies

Unlike [cargo2nix] there is no generated Nix code; unlike [naersk] and `buildRustPackage`, dependencies are not rebuilt as 1 blob.

## Install

Add the flake input:

```nix
inputs.nocargo = {
  url = "github:kp2pml30/nocargo";
  inputs.nixpkgs.follows = "nixpkgs";
  # Only used by nocargo's own checks.
  inputs.git-hooks.follows = "";
  # Optional: bump the crates.io index independently with `nix flake update registry-crates-io`.
  # inputs.registry-crates-io.follows = "registry-crates-io";
};
# registry-crates-io = { url = "github:rust-lang/crates.io-index"; flake = false; };
```

The project needs a `Cargo.lock` generated by `cargo`.

## Usage

```nix
{
  outputs = { nixpkgs, nocargo, ... }@inputs:
    let
      system = "x86_64-linux";
      pkgs = nixpkgs.legacyPackages.${system};

      # Attrset of profiles (`release`, `dev`, ...), each mapping member names to derivations.
      ws = nocargo.lib.${system}.mkRustPackageOrWorkspace {
        # Directory with `Cargo.lock` and the top-level `Cargo.toml`.
        src = ./.;

        # Registries other than crates.io, initialized with `mkIndex`.
        extraRegistries = {
          # "https://example-registry.org" = nocargo.lib.${system}.mkIndex inputs.example-registry { };
        };

        # Git dependencies, keyed by the `Cargo.lock` source without the `git+` prefix and `#hash` suffix.
        gitSrcs = {
          # "https://github.com/some/repo?rev=0123..." = inputs.some-repo;
        };

        # Extra `mkDerivation` arguments for crates; common `-sys` crates live in `crates-io-override/`.
        buildCrateOverrides = {
          # Dependencies are referenced by package id.
          "zstd-sys 2.0.1+zstd.1.5.2 (registry+https://github.com/rust-lang/crates.io-index)" = old: {
            nativeBuildInputs = [ pkgs.pkg-config ];
            propagatedBuildInputs = [ pkgs.zstd ];
          };
          # Local crates are referenced by name.
          mypkg = old: { nativeBuildInputs = [ pkgs.git ]; };
        };

        # Defaults to rustc from nixpkgs.
        # rustc = ...;
      };
    in
    {
      packages.${system} = ws.release // {
        # Explicit features replace `default` unless it is listed.
        mypkg-custom = (ws.release.mypkg.override { features = [ "feature1" ]; }).bin;
      };
    };
}
```

Each member is the library derivation (outputs `out` and `dev`); its binaries are in the `bin` attribute: `nix build .#mypkg.bin`.
